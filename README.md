# Token Launch Radar

Entry for the make.fun bounty **“Build the best token launch radar”** (`token-radar-01`).

A small, fully offline radar for token launches: a TypeScript generator
(`main.ts`) scores simulated launch candidates, estimates a fair value for
each one, attaches a concrete farm plan, and writes a ranked board
(`board.json`). A dependency-free static dashboard renders that board with
search, filtering, sorting and a detail view.

> ⚠️ **Data honesty:** every entry is **simulated example data** constructed
> locally in `main.ts` (seed name/chain/category tables + a deterministic
> PRNG, seed `20261126`). It is **not** real on-chain data, not scraped from
> any launchpad, and is not financial advice. Each row in `board.json`
> carries a `dataNote` saying so. To use real data, replace `buildSeeds()` /
> `buildEntry()` inputs with a real feed — the scoring, valuation and
> farm-plan pipeline downstream stays the same.

## How to run

Requirements: Node.js 22 or later. No `npm install` — zero dependencies.

```bash
# Node 23 / 24 (native TypeScript type-stripping)
node main.ts

# Node 22
node --experimental-strip-types main.ts
```

This regenerates:

- `board.json` — 120 token entries, ranked by opportunity score
- `dashboard/data.js` — the same entries embedded for offline dashboard use

Re-running is deterministic: same seed, same fixed time anchor
(`2026-11-26T00:00:00Z`), same output.

### Open the dashboard

Just open `dashboard/index.html` in any browser (double-click / `file://`
works). No server is needed:

- If the page is served over http(s), it first tries to fetch
  `../board.json`; on `file://` (or if the fetch fails) it falls back to the
  embedded copy in `dashboard/data.js`.
- **Board view:** stat header (entries, total estimated value, upcoming,
  low-risk count) + a card grid ranked by opportunity.
- **Detail view:** click any card for the full record — launch data,
  liquidity/lock, heat breakdown, risk, estimated value + method, and the
  complete farm plan (strategy, allocation, entry window, actions, exit
  rule, review cadence).
- **Filters:** free-text search (name/symbol), chain, risk level, category,
  launch status; sorting by opportunity, estimated value, heat, risk
  (low first) or launch time.

## Design

Pipeline in `main.ts`:

1. **Seeds** — 120 unique simulated launches across 8 chains (Solana,
   Ethereum, Base, Arbitrum, BNB Chain, Sui, Avalanche, Aptos) and
   8 categories (AI, DePIN, Gaming, Meme, DeFi, RWA, Infra, Social), each
   with launch time, initial market cap, liquidity, lock %, float, vesting,
   audit status, team status and heat inputs (social mentions, search
   trend, holder growth).
2. **Heat score (0–100)** — weighted blend of search trend (45%),
   log-scaled social mentions (35%) and holder growth (20%).
3. **Risk score (0–100, higher = riskier)** — additive penalties for
   no/unknown audit, anonymous team, unlocked liquidity, low float,
   zero vesting, thin liquidity and meme category; bucketed into
   low / medium / high / extreme.
4. **Estimated value** — `estimatedValueUsd` = initial market cap × an
   upside multiple driven by heat and discounted by risk, with the method
   recorded per row in `estimatedValue.method`.
5. **Farm plan** — rule-based per risk bucket: extreme = monitor only (0%
   allocation), high = 1% small snipe / dip-wait with fast ladder-out,
   medium = 3% staged entry + points farming, low = 5% core farm with
   LP/staking. Every plan includes an entry window, concrete actions, an
   exit rule and a review cadence.
6. **Opportunity score & ranking** — heat 55% + safety (100 − risk) 35% +
   liquidity depth bonus; the board is sorted by it and `rank` assigned.
